# step2.链二叉树  
## 构造链二叉树      
为了更方便，我把构造二叉树的代码写在下面（在3.step_2.c里也有）   
````
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int data;                       // 节点存储的数据
    struct TreeNode *left;          // 左子树指针
    struct TreeNode *right;         // 右子树指针
} TreeNode;





TreeNode* create_node(int value){          
    TreeNode *Node=(TreeNode *)malloc(sizeof(TreeNode));       //为节点分配内存
    if (Node==NULL)
    {
        printf("内存分配错误\n");                          //判断是否分配失败
        exit(1);
    }
    Node->data=value;                    //赋值date
    Node->left=NULL;                    //使left和right指向NULL
    Node->right=NULL;
    return Node;                        //返回创造的节点
}


               
int main(){                               //构造链二叉树                  
    TreeNode *root;
    root=create_node(1);                     
    root->left=create_node(2);
    root->right=create_node(3);
    root->left->left=create_node(4);
    root->left->right=create_node(5);
    root->right->left=create_node(6);
    root->right->right=create_node(7);
    return 0;
}
````
### 聪明的你会发现，只使用简单的for循环无法实现这个打印函数。请你讲讲问什么无法实现    
#### 原因： 
**1.因为for的循环语句只能选择一个方向走动，而这个二叉树的每个节点（除叶节点）都有两个分支，for的循环语句无法两个方向都走，一旦选择了左孩子就无法选右孩子这样就没法遍历全部二叉树节点。**  
**2.又因为for循环无法返回原来的父节点所以同样使其无法在打印完一个节点的子节点后再打印另一个子节点。**  
**所以单用for循环是无法遍历二叉树的。**
